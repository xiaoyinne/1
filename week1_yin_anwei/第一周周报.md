# 尹安伟第一周周报

本周完成 WSL2、Ubuntu 22.04、ROS2 Humble 和 FAST-LIO 环境配置，跑通 Hilti 数据播放、FAST-LIO 建图、地图保存、轨迹导出和 ATE 评估流程。

## 3 个卡点及解决办法

卡点：FAST-LIO 显示初始化完成，但一直没有点云和里程计输出。
节点启动后停在 Node init finished，检查 /cloud_registered 和 /Odometry 时没有消息。

解决办法：分别检查 bag 是否正在播放、雷达和 IMU 是否有数据、订阅话题是否正确，区分“节点正在运行”和“真正收到数据”。后续通过接收计数进一步发现点云输入缺失，将点云订阅改为 RELIABLE 并调整队列后，两次半速回放均完整接收到输入。

卡点：点云逐渐漂移、移出视野，保存的地图在 CloudCompare 中看起来像一条长线。
运行中还出现过大量 No Effective Points!。切换 RViz 的显示坐标系虽然能重新看到点云，但不能证明建图已经正常。

解决办法：修正 Hesai 点云时间字段的读取，将绝对时间转换为相对帧头的帧内时间；采用官方雷达与 IMU 外参，并调整过滤参数。重新建图后检查地图结构，再用轨迹与真值的 ATE 评估验证结果，而不是只看是否有点云显示。

卡点：配置了地图保存路径，但运行结束后找不到 PCD 文件。
设置 map_file_path 和开启 pcd_save_en 后仍没有文件；尝试 pointcloud_to_pcd 时还出现了 No executable found。

解决办法：检查源码发现，点云累计保存代码被整段注释，仅修改配置无法生效。恢复累计逻辑，并让退出保存使用配置中的路径；重新编译、回放数据并正常退出后，成功生成 PCD，再用 CloudCompare 打开检查。

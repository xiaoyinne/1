# 尹安伟第一周周报（草稿）

本周完成 WSL2、Ubuntu 22.04、ROS2 Humble 配置及 FAST-LIO 编译，使用 Hilti `exp18_corridor_lower_gallery_2` 序列跑通“bag → 建图 → 轨迹评估”。已保存约 704 万点的 PCD 地图及同次运行的 TUM/KITTI 轨迹，并在 CloudCompare 查看建筑结构。对匹配位姿做 SE(3) 对齐后，evo 平移 ATE RMSE 为 **0.167 m**，最大误差 **0.433 m**，评估未做尺度校正。

三个主要卡点及解法：① ROS1 bag 无法直接使用当前 ROS2 存储插件读取，通过 rosbags 转换，并处理生成 metadata 的 QoS 格式兼容问题；② Hesai 点云使用 FLOAT64 绝对秒 `timestamp`，与原 Velodyne `time` 字段不同，修正点类型和帧内相对时间处理，使用官方雷达-IMU 外参，调整窄走廊近距过滤和体素参数，采用半速回放；③ PCD 累计保存代码被注释，恢复累计并让退出保存使用配置路径，实际验证了非空文件生成。

当前限制：原速运行仍不稳定，地图仍有零散远距离点；ATE 针对匹配轨迹点，不能替代地图点级质量评估。后续将归档代码、配置、地图及评估材料，按培养方案进入第二周对应分线任务。

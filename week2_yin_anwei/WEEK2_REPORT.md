## 2. Scan Context 离线回环演示
数据：KITTI raw 2011_09_30_drive_0020_sync。
固定每 5 帧采样，共 220 帧。
20 环、60 扇区、80 米范围；排除最近 30 秒；
环向索引取 10 个候选，SC 接受阈值为 0.15。

- 有效历史查询：162。
- 按 OXTS 参考位置 5 米标准，存在附近历史帧的查询：54。
- 上述 54 个查询的第一名均在参考位置 5 米内。
- 通过 SC 阈值：23；其中参考位置较远的候选：0。
- 23 个候选全部通过 ICP 几何筛选。
- ICP 初值仅使用 SC 旋转和零平移，不使用参考位姿初始化。
- 平移参考误差中位数/最大值：0.051629 / 0.112613 米。
- 旋转参考误差中位数/最大值：0.119786 / 0.184076 度。

参考位置只用于评估，不参与描述子候选选择或排序。
23 对匹配来自同一序列，不代表 23 个独立回环事件。
OXTS 是参考位姿；上述配准误差不是轨迹 ATE。
上述 KITTI 实验未实现在线重定位联动、闭环优化或跨 session 验证。新增的 NCLT 跨日期实验见第6节。

## 6. NCLT 跨日期补充（2026-10-16）

学生三主数据集为 NCLT + Hilti；KITTI 结果作为补充。NCLT 使用2012-01-08的1296帧建库，2012-02-05的1306帧查询。描述子及检索不读取参考位置，ICP初值只使用SC旋转和零平移；参考位姿用于事后评价。

| 阶段 | 结果 |
|---|---:|
| 参考位置5米内存在历史帧的查询 | 1152 |
| 粗筛前10包含附近历史帧 | 1108 |
| 精排第一名参考位置在5米内 | 1079 |
| SC阈值通过 | 366（附近347，较远19） |
| ICP几何筛选通过 | 355（附近347，较远8） |
| 355个几何通过候选的平移参考误差中位数 / 最大值 | 0.066682 / 52.545286 m |
| 355个几何通过候选的旋转参考误差中位数 / 最大值 | 0.637553 / 179.935788° |

355/366 是几何筛选通过比例，不能称为定位成功率。参考位置附近也不保证配准姿态正确。图示查询73的平移参考误差为0.038m，查询1294虽通过几何筛选，平移参考误差仍达17.626m。

事后标记8个单环描述子退化候选，其中5个通过几何筛选。假设拒绝这5个，将同时移除3个位置附近候选和2个较远候选，仍剩6个较远候选；该诊断没有修改原始结果，也不构成已验证的算法改进。

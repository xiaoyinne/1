# 固定不同朝向的基地巡检

路线S-A-B-C-S。固定目标：A=(0.05,0.65,90°)，B=(0.85,3.25,180°)，C=(-0.80,-0.10,0°)，返回S=(0.05,-0.05,90°)。出生位姿S=(0.05,-0.05,90°)。每轮使用相同目标位姿，重新启动模拟器独立执行完整四段，正式三轮共十二次任务。

导航参数固定：AMCL、NavFn A*、DWB；到点容差0.12米/0.10弧度，NavFn附近终点搜索容差0.15米。外部评价仍要求实际位置误差≤0.25米、最短朝向误差≤0.25弧度且确认停稳。

本组三轮：导航任务成功12/12，位置达标11/12，朝向达标12/12，联合达标11/12。原始结果、输入快照和清理记录在formal中。预运行单独保留在preflight中，不混入正式统计。

在ROS2 Humble/Gazebo Classic依赖齐备的Ubuntu中，将code复制到可写目录，执行 `source /opt/ros/humble/setup.bash` 后运行 `/usr/bin/python3 -s repeat_patrol.py --run --repeats 3`。程序使用ROS_DOMAIN_ID=41和Gazebo端口11361。图形启动入口为start_week5.sh，标记箭头表示各目标朝向。

等待至少两个仿真秒，并检查平移速度<0.01米/秒、角速度<0.03弧度/秒后，读取Gazebo实际位姿计算误差。导航未使用实际位姿作为定位反馈。所有正式轮次保留，初始位姿已知，随机种子未固定。没有实车、充电对接或接触碰撞测量结论。
